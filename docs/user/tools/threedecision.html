3decision Plugin for ChimeraX

The 3decision plugin provides seamless integration between ChimeraX and 3decision molecular structure databases, allowing you to search, browse, and load structures directly within ChimeraX.

Features

  • Structure Search: Search the 3decision database using keywords, protein names, or other identifiers
  • Project Browser: Navigate through 3decision projects and select structures to load
  • Direct Loading: Download and visualize structures directly in ChimeraX with proper metadata
  • Secure Configuration: Save your 3decision credentials securely within ChimeraX
  • Background Processing: All network operations run in background threads for responsive UI

Installation

The plugin can be installed through ChimeraX's package manager or manually from source.

Requirements: ChimeraX 1.10.1 or later and internet access to reach your 3decision server.

Configuration

Before using the plugin, you must configure your 3decision server connection:

  1. Open the plugin: Tools → Structure Analysis → 3decision
  2. Click the settings button (⚙️) in the top-right corner
  3. Enter your 3decision server details:
    • Server URL: Your 3decision server address (e.g., https://your-server.com)
    • API Key: Your personal 3decision API key
  4. Click Test Connection to verify your settings
  5. Click Save to store your configuration
Security Note: Your API credentials are stored locally on your computer and are not shared with anyone else.

Usage

Searching for Structures

The Search tab allows you to find structures in the 3decision database:

  1. Ensure you have a green connection indicator (●) showing you're connected
  2. Enter a search term in the search field (e.g., "ABL1", "kinase", "hemoglobin")
  3. Click Search or press Enter
  4. Wait for the search to complete and results to appear in the table
  5. Select structures using the checkboxes
  6. Click Load Selected Structures to download and visualize them

Browsing Projects

The Projects tab lets you browse 3decision projects and their structures:

  1. Click the Projects tab
  2. Click Refresh Projects to load your available projects
  3. Select a project from the list to view its structures
  4. Use Select All or Select None to quickly manage selections
  5. Click Load Selected Structures to load chosen structures with preserved project positioning

Command Line Interface

The plugin also provides command-line access:

# Open the 3decision tool
3decision

# Search for structures directly
3decision search "ABL1"

Search Results

The results table displays the following information about found structures:

  • Select: Checkbox to select structures for loading
  • External Code: PDB code or external identifier
  • Title: Structure title or description
  • Method: Experimental method used (e.g., X-ray crystallography, NMR)
  • Resolution: Structure resolution in Ångströms (if applicable)
  • Date: Deposition or modification date

Structure Loading

When you load structures from 3decision:

  • Structures are downloaded in PDB format
  • Each structure appears as a separate model in ChimeraX
  • Models are automatically named using their external codes
  • 3decision metadata is attached to models for reference
  • Loading happens in the background with progress updates

Troubleshooting

Connection Issues

  • Verify your 3decision server URL is correct and accessible
  • Check that your API key is valid and active
  • Ensure ChimeraX has internet access
  • Try the Test Connection button in settings
  • Contact your 3decision administrator for API access issues

Search Problems

  • Make sure you have a green connection status (●)
  • Try different search terms or use broader keywords
  • Check the ChimeraX Log for detailed error messages
  • Some searches may take time to process - wait for completion

Loading Failures

  • Ensure the structures are available for export from your 3decision server
  • Verify you have sufficient permissions to access the structures
  • Check your internet connection stability
  • Try loading fewer structures at once if you encounter timeouts

Plugin Not Visible

  • Restart ChimeraX after installation
  • Check Tools → More Tools if not in the main menu
  • Verify the plugin was installed correctly via Tools → More Tools → Manage Packages

API Integration

The plugin integrates with these 3decision API endpoints:

  • GET /auth/api/login - Authentication and token retrieval
  • GET /search/{query} - Structure search submission
  • GET /queues/{queue}/jobs/{id} - Search result polling
  • POST /graphql - Detailed structure information retrieval
  • POST /exports/structure - Structure export in PDB format
  • GET /exports/structure/{id} - Download exported structures
  • GET /projects - Project listing
  • GET /projects/{id}/structures/matrix - Project structure listing
SSL Note: The plugin disables SSL certificate verification to support development servers and internal APIs with self-signed certificates. This is noted in the settings dialog.
